# Credit-Card-Sales-Analysis
📊 Marketing Analytics Dashboard (Power BI / Data Visualization)
This project is a Marketing Analytics Dashboard designed to analyze customer behavior, digital spending patterns, and transaction trends across multiple platforms.
📄 Dashboard File: Marketing Dashboard.pdf

🚀 Project Overview
The dashboard provides a comprehensive view of marketing performance, focusing on:

Customer segmentation
Digital spending patterns
Platform usage (Web, iOS, Android)
Transaction trends and forecasts

It helps stakeholders understand customer engagement, channel performance, and revenue contribution.

✨ Key Features


📈 Trend Analysis

Monthly spend trends (Sep 2019 – Feb 2020)
Transaction growth and fluctuations



👥 Customer Segmentation

Diamond, Platinum, Gold categories
Segment-wise digital spend distribution



💻 Platform Insights

Spend split across:

Web
Web + iOS
Android


Platform usage comparison



💳 Card Family Analysis

Premium, Platinum, Gold cards
Spend distribution by card type



🔄 Transaction Behavior

Active vs Dormant customers
Customer cohort tracking




📊 Key Insights

Majority of digital spend is driven by Web users (~161M) followed by Web + iOS (~43M) and Android users (~6.8M)
High concentration of spending is observed in premium customer segments
Monthly spend shows stable but slightly fluctuating trends (~39M–43M range)
Transactions are heavily dominated by active customers (~92%) vs dormant (~8%)
